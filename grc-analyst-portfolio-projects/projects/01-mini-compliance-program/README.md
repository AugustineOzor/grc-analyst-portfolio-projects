# Project 1: Mini compliance program (ISO/IEC 27001:2022)

[← Repository home](../../README.md)

## Objective

Act as the compliance officer for NovaCloud AI Solutions and build a small but complete compliance baseline: define the scope, list the assets, assess Annex A controls, assign owners and set improvement actions.

## Deliverables

| File | What it contains |
|---|---|
| [01 Scope and compliance summary](01-scope-and-compliance-summary.md) | One-page summary of scope, goal, approach, result and priorities |
| [02 Asset inventory](02-asset-inventory.md) | 17 assets with type, classification and owner |
| [03 ISO 27001 control matrix](03-iso-27001-control-matrix.md) | 23 Annex A controls with requirement, status, maturity, owner and action |

## Key results

- **23 controls** assessed across the Organizational, People, Physical and Technological themes (the brief asks for at least 15).
- **7 implemented, 12 partial, 4 planned**, with an average maturity of 2.1 out of 5.
- Every gap has an owner and a tracked action with a due date.

## Improvements over the basic brief

- Added a **maturity score** and a **current state** for each control, so the status can be checked and re-scored.
- Split "gaps" into **Partial** and **Planned**, so work in progress is not hidden.
- Covered all four Annex A themes, not just technical controls.
- Linked every action to the shared action list used by the [dashboard](../06-compliance-dashboard/README.md) and the [internal audit](../07-mock-internal-audit/README.md).
