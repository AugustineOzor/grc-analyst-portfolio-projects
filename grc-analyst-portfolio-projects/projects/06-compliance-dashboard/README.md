# Project 6: Compliance dashboard

[← Repository home](../../README.md)

## Objective

Turn the risk and control data into visual metrics: control coverage, maturity, risk status and remediation progress, in a color-coded dashboard.

## Deliverables

| File | What it contains |
|---|---|
| [Dashboard write-up](dashboard.md) | Dashboard image, how to read it, metric definitions, the shared action list and a Notion build guide |
| [NovaCloud_Compliance_Dashboard.xlsx](NovaCloud_Compliance_Dashboard.xlsx) | Excel workbook with Controls, Risks and Actions sheets and a formula-driven Dashboard with four charts |
| [Dashboard image](assets/dashboard.png) | Export for the portfolio |

## Key results

- **23 controls, 12 risks and 24 actions** tracked in one place.
- The workbook has **152 formulas and 4 charts**; change a status or date and every figure updates.
- The same numbers appear in the image, the workbook and the other projects, so the dashboard is checkable.

## Improvements over the basic brief

- Used **formulas**, not typed numbers, so the dashboard is a working tool.
- Added **overdue** and **days-to-due** logic driven by a snapshot date.
- Showed **inherent, current and target** risk side by side, not one number.
- Added a **Notion build guide**, since the brief allows either tool.

Data visualization · Metrics design · Excel formulas and charts · Reporting to leadership
